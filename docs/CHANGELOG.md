# 更新日志

## 0.1.1 · 2026-10-28

- 每日新闻改为热摸爽热榜：综合榜对齐站点首页顺序，新增站点全部分类，支持左右滑动切换。
- 新闻改为每小时自动更新，同一小时内不重复抓取；切回新闻页、回到前台都会立即检查。
- 新增收藏列表与顶部搜索框，可快速找回收藏的文章或按关键词检索。
- 设置页新增更新日志入口，集中查看每个版本的改动。
- 阅读页保留文末「查看全文」链接，可一键跳转原文。

## 0.1.0 · 2026-10-18

- 新增每日新闻页，早晚两次汇总当天要闻，每条附一句话概括并可跳转原文。
- 每个订阅源可设置筛选侧重：时效优先、深度优先或均衡。
- 阅读页自动清理网页导航、页脚与广告残留，正文更干净。
- 封面与正文配图加载更快，长文打开不再卡顿。
- 全新紫底白字应用图标。

## 0.0.1 · 2026-10-11

- Milla 首个版本：多订阅源信息流，不同来源交替排列。
- 按质量与新鲜度综合排序，可调整权重、半衰期与每源条数。
- 支持订阅源启用停用、收藏、深浅色模式与背景刷新。
